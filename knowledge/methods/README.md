# 交易手法與方法論筆記

使用者看到、要學起來的別人的做法（Threads 串文、螢幕錄影等）。每份筆記要寫清楚：**來源與日期、讀得到／讀不到的部分、自述 vs 可驗證、和既有知識（`knowledge/gooaye/`）的對照、要小心的地方、若要驗證要測什麼**。
這裡的東西是學習用，**不是進出場建議**，本專案不會依它自動下單。

| 筆記 | 來源 | 一句話 |
|---|---|---|
| [pingyunhuang-台指期突破加碼](pingyunhuang-台指期突破加碼.md) | Threads @pingyunhuang（作者說是十幾年前的舊文） | 一天只做一個方向、突破買、拉回加碼一次、賠錢絕不加碼；先決條件是資金（台指至少 100 萬）與「滿倉／單筆」比值（他 1:120、新手 1:4）；日虧 3～5% 上限；寧可小賠不要小賺出場 |
| [交易明細個案-台指期順跌加空7口](交易明細個案-台指期順跌加空7口.md) | 使用者給的 10/30 成交回報（7 口大台、均價 46,689、11:30 一次回補 46,320，+369 點／口） | 用它校準：合格線 1.0%、順勢加碼；出場規則仍未知（第 2 頁、回補原因待補） |

追蹤的帳號放在 `config/sources.yaml` 的 `threads_learn_accounts`：他們的新貼文不管有沒有提到公司，一律進待檢視清單（標籤「學習」），由研究員整理到這個資料夾。
