# 微台機器人：怎麼建、怎麼設定、怎麼用

> 微台（台指期日內順勢突破）的日盤／夜盤訊號、收盤彙總、績效都從同一個 Telegram 機器人推送，並且能傳字給它查績效。只是模擬計畫帳、只發訊號、不下單，也不是投資建議。

## 一次性設定（約 3 分鐘，在你的手機 Telegram 上）
1. 在 Telegram 搜尋 **@BotFather**，傳 `/newbot`，依指示取一個顯示名稱（例如「微台」）和一個結尾是 `bot` 的帳號名稱；它會回一串 **token**（像 `123456789:ABC...`）。
2. 搜尋你剛建好的機器人，按 **Start**（沒按的話機器人無法傳訊息給你）。
3. 到 GitHub 儲存庫 → **Settings → Secrets and variables → Actions → New repository secret**：
   - 名稱 `TELEGRAM_FUTURES_BOT_TOKEN`，值貼上 token。
   - `TELEGRAM_FUTURES_CHAT_ID` **可以不填**：沒填就沿用你現有的 `TELEGRAM_CHAT_ID`（同一個人私訊不同機器人的 Chat ID 相同）。
4. 完成。沒設定這個機器人時，微台訊息仍照舊從進出場機器人（沒有的話從盤勢機器人）送出，不會中斷。

## 機器人推什麼
- 日盤、夜盤的進場、加碼、出場、停損訊號與收盤彙總（原本在進出場機器人，設定後改由微台機器人送）。
  「💰 損益總結」（本場損益、本月累計、今年累計）**只在全數出場時附一次**（停損、收盤前出場、虧損上限，出完已空手）；進場、加碼、分批出場（出一半）、盤面通知都不附。
  收盤彙總不重複：收盤時已經空手就不附，還有未平倉（沒有全出訊號）才附。
- 每月結算：月初第一個收盤（日盤或夜盤）自動推上個月的場次、賺賠、勝率、當月最大回落、最佳與最差一場、今年累計；每個月只推一次。
- 夜盤報價中斷提醒。
- 你叫它的時候回的績效。
- 實單記帳、盤前計劃、盤後結算**仍在進出場機器人**，不會搬。

## 你可以傳給它的字
| 傳 | 回 |
|---|---|
| `績效`（或 `微台`） | 累計損益、勝率、平均賺賠、最近 8 場 |
| `今天`（或 `進行中`） | 今天各場次的損益 |
| `明細`（或 `紀錄`） | 最近一場的觸發紀錄（時間、價格、訊號） |
| `月結`（或 `月報`） | 每月結算（最近 6 個月） |
| `年度`（或 `年報`） | 年度績效表：全年場次、勝率、損益、最大回落、最佳與最差月、各月損益 |
| `說明` | 指令清單 |

- 回覆由常駐監看處理，**約每 2 分鐘一次**，不是即時。
- **進行中的場次要等收盤後才寫進紀錄**，盤中問「績效」看到的是上一場結束時的數字。
- 只回應你本人（Chat ID 對得上）的訊息；亂打的字不會被當成下單。
- 想隨時主動推一次績效：GitHub → Actions → futures-report → Run workflow。

## 每月結算與年度績效表（會存檔）
- `state/futures_yearly.md`：每月結算表＋年度績效表，每次觸發紀錄更新就自動重寫，跟著 `state/` 一起 commit，想看就直接開這個檔。
- 只算**已結束、有進場**的場次；場次歸月份＝場次代號的日期（夜盤算開盤那天：11/30 夜盤跨到 12/1 凌晨，仍算 11 月）。月底夜盤沒收完，那個月先不結算。
- 月結算從 2026-11 開始；日盤上線前只有一筆 10/30 的 0 點測試紀錄，不結算。
- 已結算的月份記在 `state/futures_log.json` 的 `settled`，不會重複推。
- 年度表跨年會自動多一列：每年各自一個「每月結算」表與年度總表。
- 手動看：`python -m market_intel futures-report --dry --view month`（或 `--view year`）。
