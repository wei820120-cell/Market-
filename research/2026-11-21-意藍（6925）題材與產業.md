## 3. 產業鏈因果（垂直）
**社群／新聞／論壇資料 → 資料庫與分析平台（OpView、fynaview；意藍）→ AI 檢索與代理（AI Search、Agent Tools API）→ 企業、品牌、公關與金融研究客戶**。
- **瓶頸**：資料取得與授權（合規、平台政策，沒查到細節，推論）與訂閱續約（85%）；毛利率高、規模小（營收約 2 億元）。
- **AI Agent 新通路**：Agent Tools API 讓通用 LLM 直接取用意藍資料；這是新分銷方式，也讓通用 LLM 廠商成為通路與潛在替代（推論）。

## 4. 相關推進力（水平）
- **LLM 與 Agent 生態**：通用 LLM 加搜尋功能可能取代部分問答類產品；意藍把資料庫做成 Agent 可呼叫的工具以對應（公司說法）。
- **相鄰題材**：資訊服務與資安股在 11/16 因「政府研議擴大《資通安全管理法》納管範圍」逆勢漲停（既有研究《資通（2471）》《安碁資訊（6690）》）；意藍不在該題材內，沒有關聯證據。

## 5. 慣性、痛點與限制（思辯）
- **慣性**：訂閱制續約帶來穩定收入；但成長慢（前十月年增 4.6%）。
- **痛點**：AI Agent 與 AI Search 尚未反映在營收；2025 年全年營收數字各來源不一（約 2.1 億元，「年增 20%」與 2024 年 1.83 億元對不上）。
- **限制**：2026 年數字單一來源；沒有 11/20 股價、市值與量比；沒有客戶集中度、資料授權與研發費用資料。
- **擴產與稼動檢核**：不適用（軟體訂閱）。
- **敘事陷阱自查**：①把「AI Agent 題材」當成營收動能（營收年增僅 4.6%）；②把 Q3 EPS 年增 16% 當成加速（前三季 EPS 年減 2%）；③把選舉輿情聯想當成漲停原因（沒有證據）；④把展會發表當成客戶簽約；⑤把公司的「台灣最大」說法當成獨立市占資料。

## 6. 誰受惠、誰受傷（方向性推論）
- **受惠（情境）**：意藍——若 Agent Tools API 帶來新客戶與用量，AI Agent 題材才會反映在營收；目前沒有證據。
- **受傷（情境）**：通用 LLM 內建搜尋與資料功能取代其問答產品；平台限制資料取用。
- **中性**：沒有同業可比（本檔沒查）。
